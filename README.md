# Symbolon – vydání / Releases

**Česky** · [English below](#english)

**Symbolon** je desktopový editor pro Windows: vlevo zdroj, vpravo živý náhled (Markdown, PlantUML, JSON, YAML, CSV,
logy, obrázky a další formáty), s lokální AI a vestavěným Gitem. Tohle je **veřejný repozitář jen na vydání** –
najdete tu instalátory (záložka **Releases**), žádný zdrojový kód.

## Instalace

1. Otevřete nejnovější vydání v záložce **Releases** a stáhněte `symbolon-setup-X.Y.Z.exe`.
2. Spusťte ho. Instaluje se jen pro vás (do `%LOCALAPPDATA%\Programs`), správce nepotřebujete.
3. **Windows SmartScreen** může ukázat „Windows ochránil váš počítač“ – instalátor je podepsaný *testovacím*
   certifikátem, který Windows zatím nezná. Klikněte na **Další informace → Přesto spustit**.
4. Novou verzi vám Symbolon sám ohlásí lištou pod hlavním panelem (jednou denně se zeptá github.com, která verze je
   poslední, a nic dalšího neposílá; jde to vypnout v Nastavení → Aktualizace). Stažení a instalaci děláte vy.

# Symbolon – Releases

**Symbolon** is a desktop editor for Windows: source on the left, live preview on the right (Markdown, PlantUML,
JSON, YAML, CSV, logs, images and more), with a local AI and a built-in Git. This is a **public repository for
releases only** – you will find the installers here (the **Releases** tab), no source code.

## Installation

1. Open the latest release in the **Releases** tab and download `symbolon-setup-X.Y.Z.exe`.
2. Run it. It installs for your account only (into `%LOCALAPPDATA%\Programs`); no administrator is needed.
3. **Windows SmartScreen** may show "Windows protected your PC" – the installer is signed with a *test*
   certificate that Windows does not know yet. Click **More info → Run anyway**.
4. Symbolon announces a new version itself with a bar under the main toolbar (once a day it asks github.com which
   version is the latest and sends nothing else; you can turn it off in Settings → Updates). You download and
   install it yourself.
